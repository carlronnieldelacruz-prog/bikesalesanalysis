# [Project #3: Bake Sales Analysis in Excel]

* Data was taken from kaggle: https://www.kaggle.com/code/sadiqshah/bike-store-sales-in-europe/data
* Using Excel, the project analyzed and explored the data using Pivot Tables, and Charts

  #### Overview
This project analyzes customer demographics and purchasing behavior using a Bike Buyers dataset in Microsoft Excel.

The objective was to transform the raw customer data into a structured working dataset, perform analysis using Pivot Tables, and create an interactive Bike Sales Dashboard to identify patterns and trends in bike purchases.

#### Analysis Performed
This project explores relationships between decision on bike purchase and customer characteristics including
1. Gender
2. Income
3. Age Bracket
4. Commute Distance
5. Region

through an interactive dashboard and pivot tables for easier visualization
